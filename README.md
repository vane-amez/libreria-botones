
Explicación de los 4 estilos en el botón # 100:
1. background: linear-gradient: Crea una transición suave entre dos colores de fondo con un hover para invertir los puntos de inicio y fin del degradado para crear una transición de iluminación muy fluida y agradable a la vista.
2. transition: all 0.3s cubic-bezier: Controla el tiempo y el ritmo en el que cambian los estilos (borde, color, sombra, posición) al pasar el cursor, evitando saltos bruscos.
3. transform: translateY(-2px): Desplaza el elemento en el eje vertical (Y) hacia arriba o hacia abajo utilizando la tarjeta gráfica del dispositivo, lo que garantiza que la animación sea fluida y no desacomode otros textos de la página.
4. box-shadow: (Sombras con transparencia RGBA) Añade sombras tridimensionales alrededor de la caja del botón.
